### 11.1.3 Updating Entities

**DI API**

> **Sample Code**
>
> <!-- code: c231-01 -->
> ```
> SAPbobsCOM.Documents order =
> (Documents)oCompany.GetBusinessObject(BoObjectTypes.oOrders);
> order.GetByKey(2);
> order.Comments = "New comments";
> order.Update();
> ```

**Service Layer**

> **Sample Code**
>
> <!-- code: c231-02 -->
> ```http
> PATCH /Orders(2)
> {
>   "Comments":"New comments"
> }
> ```
