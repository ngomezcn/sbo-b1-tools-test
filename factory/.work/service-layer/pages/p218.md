**ROUND**

Rounds a numeric value to the nearest integer.

**Usage**

<!-- code: c218-01 -->
```
ROUND(numeric)
```

**Parameters**

<!-- table: t218-02 -->
| Parameter | Type | Description |
|---|---|---|
| numeric | number | The numeric value to round |

**Examples**

<!-- table: t218-03 -->
| Formula | Return value |
|---|---|
| `ROUND(4.5)` | 5 |
| `ROUND(4.4)` | 4 |
| `ROUND(-4.5)` | -4 |
